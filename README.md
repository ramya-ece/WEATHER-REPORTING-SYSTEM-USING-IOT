# Weather Reporting System using IoT

A smart IoT-based weather monitoring system that collects real-time environmental data using sensors and provides accurate weather updates through a web interface.

## Features

### Sensor Capabilities
- Temperature monitoring (-40°C to 80°C)
- Humidity measurement (0-100% RH)
- Atmospheric pressure (300-1100 hPa)
- Rainfall detection
- Wind speed and direction
  
### System Features
- Real-time data collection & processing
- Web dashboard for data visualization
- Mobile app notifications
- Historical data analysis
- Weather forecasting
- Alert system for extreme conditions

## Tech Stack

### Hardware
- ESP32 microcontroller
- DHT11 temperature/humidity sensor
- RPS pressure sensor
- Rain sensor module
- LCD
- LDR
- Buzzer

### Software
- Arduino IDE for sensor programming
- MQTT protocol for IoT communication
- Chart.js for data visualization
